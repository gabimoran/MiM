## Descripción del Proyecto
Este proyecto tiene como objetivo desarrollar un modelo de inteligencia artificial que evalúe la calidad de las imágenes capturadas para el diagnóstico de retinopatía diabética. La correcta clasificación de las imágenes en "calidad adecuada" o "calidad insuficiente" es fundamental para asegurar diagnósticos precisos y evitar repeticiones innecesarias de estudios.

## Motivación
La detección temprana de la retinopatía diabética es clave para prevenir la ceguera irreversible. Sin embargo, la falta de acceso a oftalmólogos y la baja frecuencia de controles oftalmológicos dificultan la identificación de esta enfermedad. Este proyecto busca mejorar el proceso mediante la automatización de la evaluación de la calidad de las imágenes.
